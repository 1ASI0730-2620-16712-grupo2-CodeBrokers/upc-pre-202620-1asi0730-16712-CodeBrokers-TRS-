# Fundamentos de Desarrollo Web — HTML y CSS

Curso introductorio para estudiantes de 12 a 17 años. Seis lecciones de aproximadamente 10 minutos. **Sin instalaciones:** todas las prácticas se realizan en un navegador con [CodePen](https://codepen.io/pen/).

## Cómo usarlo en CodePen

1. Abre https://codepen.io/pen/ en el navegador.
2. Entra a `starter-files/01-introduccion` y abre `html.txt`.
3. Copia el contenido al panel **HTML** de CodePen; copia `css.txt` al panel **CSS**.
4. Modifica el código mientras ves el resultado. Comprueba tu solución en `completed-examples/01-introduccion`.
5. Repite para cada lección. En CodePen, pega el **fragmento** de `html.txt`, no el documento `vista-previa.html` completo. Este último sirve para abrirlo localmente como referencia opcional.


## Secuencia

| Lección | Tema | Carpeta |
|---|---|---|
| 01 | Introducción al desarrollo web | `01-introduccion` |
| 02 | Etiquetas y estructura HTML | `02-html-basico` |
| 03 | Listas, imágenes y enlaces | `03-elementos-html` |
| 04 | Colores y tipografías | `04-css-basico` |
| 05 | Centrado, bordes y espacios | `05-diseno-css` |
| 06 | Proyecto final y errores comunes | `06-proyecto-final` |

## Estructura

- `starter-files/`: código de partida de cada lección.
- `completed-examples/`: código terminado y archivos HTML de vista previa.
- `scripts/`: guías de grabación de cada lección.
- `docs/course-plan.md`: plantilla Markdown de la entrega.

## Responsabilidades del equipo

Cada integrante debe elaborar y grabar su lección, revisar el código, contribuir mediante commits al repositorio público y proporcionar el enlace a su video no listado y a su práctica en CodePen.

## Material de exposición

En `presentaciones/` hay una presentación editable para cada integrante. En `scripts/` están los guiones detallados con tiempos, narración y acciones. La presentación conjunta se entrega por separado dentro del paquete integral.
